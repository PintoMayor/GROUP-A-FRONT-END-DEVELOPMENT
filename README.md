 # CivicPulse

**Community Problem Reporting and Tracking Website**

CivicPulse is a web-based platform that helps people report common problems in their communities, such as bad roads, blocked drainage, poor waste disposal and broken streetlights, and track the progress of those reports through a simple, user-friendly interface.

## Problem Statement

Many community problems are reported informally, which makes it hard for residents to follow up or know whether any action has been taken. There is a need for a simple digital platform where community issues can be reported, organized and tracked.

## Aim and Objectives

**Aim:** To develop a responsive website that makes community problem reporting and tracking easier.

**Objectives:**

- Create a user-friendly interface for reporting community problems.
- Allow users to view, search and filter submitted reports.
- Display the status of each report.
- Provide an administrative dashboard for reviewing reports and posting responses.
- Use JavaScript to update website content dynamically through DOM manipulation.
- Design a responsive website that works on mobile phones and computers.

## Features

1. **Homepage:** introduces CivicPulse and its purpose.
2. **Report form:** lets users enter the details and location of a community problem.
3. **Community reports section:** for viewing and searching submitted reports.
4. **Report tracking:** for checking the progress of an issue.
5. **Administrative dashboard:** for viewing reports, updating their status and providing responses.
6. **Responsive interface:** a visually appealing design with simple animations.

## Technologies Used

| Technology | Purpose |
| --- | --- |
| HTML | Structures the website pages and forms |
| CSS | Styles the website and creates an attractive design |
| Flexbox | Arranges elements and creates responsive layouts |
| JavaScript | Handles form submissions, validation, searching and filtering |
| DOM Manipulation | Displays reports dynamically and updates their statuses on the page |

**Planned (if time permits):**

## Expected Outcome

A functional website prototype that demonstrates how web technologies can be used to address community problems. The project shows an understanding of HTML, CSS, Flexbox, JavaScript and DOM manipulation, and provides a foundation for future improvements.
