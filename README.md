# CivicPulse – Community Problem Reporting Website

## About the Project

CivicPulse is a website that allows people to report problems in their communities, such as bad roads, blocked drainage, waste disposal problems, and broken streetlights.

The aim of this project is to make it easier for people to report problems and follow up to see if action has been taken.

I chose this project because I wanted to use what I have been learning in Frontend Development to create something that can help people in their communities.

## Technologies Used

I am building this project with the following:

- **HTML:** To create the structure and content of the website.
- **CSS:** To style the website and make it attractive.
- **JavaScript:** To add functionality and make the website interactive.
- **Flexbox:** To arrange items properly on the page.
- **Span:** To style specific words or parts of a text differently.
- **CSS styling:** To work on colours, spacing, buttons, backgrounds, and the general appearance of the website.

I have also done some personal research to learn a few additional ways of improving the design and functionality of my project.

## Main Features

### 1. Homepage

The homepage introduces CivicPulse and explains what the website does. It also displays some reported community problems and allows users to search for reports.

### 2. Report a Problem

Users can fill in a form with details about a problem they have noticed in their community. This can include the problem's title, category, description, and location.

### 3. Track a Report

Users can enter a reference code to check the status of a report they submitted.

### 4. Admin Dashboard

The dashboard allows an administrator to view reports, update their status, and add a response.

### 5. Website Design

I am using CSS to make the website look neat, attractive, and easy to use on different screen sizes, including phones and computers.

### 6. Interactive Features

JavaScript is used to make some parts of the website respond to user actions, such as searching for reports, filtering reports by status, and submitting forms.

## How the Website Works

The website follows a simple process:

1. A user visits the website.
2. The user reports a problem in their community.
3. The user receives a reference code.
4. The user uses the code to check the report's status.
5. An administrator can review the report and update its status.

## Project Structure

The project contains HTML, CSS, and JavaScript files.

- `index.html` – The homepage.
- `report.html` – The page for reporting a problem.
- `track.html` – The page for checking a report.
- `admin.html` – The administrator's dashboard.
- `assets/css/` – Contains the CSS files used to style the website.
- `assets/js/` – Contains the JavaScript files used to add functionality.

## How to Run the Project

1. Download or copy the project folder to your computer.
2. Open the folder in Visual Studio Code.
3. Open the `index.html` file in your browser, or use the Live Server extension if you have it installed.
4. Explore the website and test its features.
